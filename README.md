# SQL desde cero — University School IA

Material del curso **SQL desde cero** del canal de YouTube **University School IA**.
No necesitas saber programar ni instalar nada: solo un navegador.

## Cómo practicar

1. Abre https://sqliteonline.com (gratis).
2. Copia el contenido de [`datos/tienda.sql`](datos/tienda.sql), pégalo en el editor y pulsa **Run**. Esto crea la base de datos de práctica **La Tiendita**.
3. Abre la carpeta de la lección y ejecuta los archivos `.sql` en el mismo orden que en el video.

## La Tiendita

| Tabla | Qué guarda |
|---|---|
| `productos` | id, nombre, categoría, precio y stock de cada producto |
| `clientes` | id, nombre y ciudad de cada cliente |
| `ventas` | qué cliente compró qué producto, cuántas unidades y cuándo |
